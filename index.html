🧮 Luhn Algorithm Breakdown

The Luhn checksum validates card number structure. Starting from the rightmost digit, every second digit is doubled. If the result exceeds 9, subtract 9. The sum of all digits must be divisible by 10.

💡 Note: This is a simulation. No real payment is processed. Card data never leaves your browser — all cryptographic operations run locally using the Web Crypto API.
